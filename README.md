# Auras suspendidas
Modelo 3D de Recinto Aula 04 realizado para el  Seminario Fundamentos de Acústica para Artes Multimediales
"Auras Suspendidas" es una obra inmersiva que fue desarrollada físicamente, este es un simulador 3D interactivo desarrollado para la visualización y planificación espacial de la instalación.
El proyecto permite explorar en tiempo real la interacción entre telas de tul suspendidas, la proyección lumínica y la volumetría del espacio expositivo.
Podes explorar la simulación interactiva entrando a este link https://victoriacabelloherrera.github.io/render-auras-suspendidas/
